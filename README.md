## 🧭 Learning Journey: 12-Month Roadmap

These repos are **structured learning logs**, not products. Each one is a stage of the roadmap, and each stage builds on the last. Inside you'll find derivations, from-scratch implementations, tests and short write-ups.

| Stage | Repository | What I learned and built |
|:---:|---|---|
| 1 | **[From Raw Data to a Real Answer](https://github.com/Yugalpoudel07/From-Raw-Data-to-a-Real-Answer)** | SQL window functions, Pandas cleaning and merging, permutation tests, power analysis, p-hacking and FDR correction, charts with confidence intervals |
| 2 | **[Mathematics for Data Science](https://github.com/Yugalpoudel07/Mathematics-for-Data-Science)** | Linear algebra, calculus and probability. Built a gradient checker, bootstrap CIs and Naive Bayes from scratch |
| 3 | **[Machine Learning Built by Hand](https://github.com/Yugalpoudel07/Machine-Learning-Built-by-Hand)** | Linear, Ridge, Lasso, logistic and softmax regression in NumPy; k-fold CV, ROC/PR curves and calibration. Matches sklearn to 8 decimal places |
| 4 | **[The Models That Win Real Problems](https://github.com/Yugalpoudel07/The-Models-That-Win-Real-Problems)** | Decision trees, random forests and boosting from scratch; XGBoost/LightGBM, SHAP, k-means, PCA, leak-free pipelines, A/B testing and Simpson's paradox |
| 5 | **[Neural Networks With Nothing Hidden](https://github.com/Yugalpoudel07/Neural-Networks-With-Nothing-Hidden)** | NumPy MLP on MNIST, hand-derived backprop with numerical gradient checks, a mini autograd engine, PyTorch training loops, CNNs, ResNet skips, transfer learning |
| 6 | **[Shipping Models and Building Transformers](https://github.com/Yugalpoudel07/Shipping-Models-and-Building-Transformers)** | FastAPI + Docker deployment with latency/cost measurements; RNN, BPE tokenizer, multi-head attention and a small GPT built from scratch |
| 7 | **[LLM Applications and Production Practice](https://github.com/Yugalpoudel07/LLM-Applications-and-Production-Practice)** | LoRA fine-tuning vs a TF-IDF baseline, quantization cost analysis, RAG with separate retrieval/generation metrics, MLflow, DVC, GitHub Actions, drift monitoring |
