## 📚 Featured Projects

### 1. **[From Raw Data to a Real Answer](https://github.com/Yugalpoudel07/From-Raw-Data-to-a-Real-Answer)**  
*Statistical honesty in data analysis. Hypothesis testing, data cleaning, publication-quality visualizations.*

- **What it covers:** SQL window functions · Pandas data cleaning and merging · Hypothesis testing (permutation tests, p-hacking, power analysis) · Matplotlib/Seaborn statistical visualization · Statistical FDR correction
- **Certifications earned:** Kaggle Learn Pandas (6/6) · Kaggle Learn Data Cleaning (5/5)
- **Core principle:** Every number comes with a confidence interval. Every cleaning decision is documented. Charts argue for a conclusion.

### 2. **[Mathematics for Data Science](https://github.com/Yugalpoudel07/Mathematics-for-Data-Science)**  
*Geometric and algebraic foundations. Linear algebra and calculus from scratch.*

- **3Blue1Brown — Essence of Linear Algebra (16/16 chapters completed):**  
  Vectors, matrices, determinants, eigenvalues, change of basis—all with visual intuition and ML applications
- **3Blue1Brown — Essence of Calculus (12/12 chapters completed):**  
  Derivatives, chain rule (→ backpropagation), integrals, Taylor series, optimisation
- **StatQuest with Josh Starmer (23/23 videos completed):**  
  Probability, distributions, confidence intervals, bootstrap, maximum likelihood
- **Implementations:** Gradient checker, bootstrap confidence intervals, Naive Bayes classifier

### 3. **[Machine Learning Built by Hand](https://github.com/Yugalpoudel07/Machine-Learning-Built-by-Hand)**  
*Derive on paper. Code from scratch in NumPy. Test against scikit-learn.*

- **From-scratch algorithms:**
  - Linear regression (closed form + gradient descent)
  - Ridge & Lasso regularization (with coefficient paths)
  - Logistic regression (likelihood → gradient by hand)
  - Softmax classification
  - Evaluation metrics: confusion matrix, precision, recall, F1, ROC/AUC, PR curves
  - Reliability diagrams & calibration
- **Every model:** Tested to 8 decimal places against sklearn
- **Cross-validation:** k-fold written from scratch, stratified splitting
- **Resources:** ISLP (Python edition), StatQuest core ML set, scikit-learn metrics docs

### 4. **[The Models That Win Real Problems](https://github.com/Yugalpoudel07/The-Models-That-Win-Real-Problems)**  
*Decision trees, random forests, gradient boosting, A/B testing on real tabular data.*

- **From scratch:** Decision trees, random forests, gradient boosting principles
- **Libraries:** XGBoost, LightGBM, scikit-learn pipelines
- **Explainability:** SHAP values for feature importance
- **Unsupervised:** k-means clustering, PCA dimensionality reduction
- **Proper ML:** Leak-free pipelines, class-imbalance demonstrations
- **Statistics:** A/B test power analysis, Simpson's paradox, peeking penalties

### 5. **[Neural Networks With Nothing Hidden](https://github.com/Yugalpoudel07/Neural-Networks-With-Nothing-Hidden)**  
*Backpropagation derived by hand. Autograd engine built from scratch. Neural networks without a framework.*

- **From scratch:** MLP trained on MNIST (pure NumPy)
- **Every gradient:** Checked numerically against hand derivations
- **Autograd:** Mini automatic differentiation engine
- **PyTorch:** Training loops, 5-seed ablation studies
- **CNN:** NumPy convolution operations, ResNet skip connections, transfer learning

### 6. **[Shipping Models and Building Transformers](https://github.com/Yugalpoudel07/Shipping-Models-and-Building-Transformers)**  
*Production ML and language models. FastAPI, Docker, deployment. Transformers from scratch.*

- **Part 1 — Production:**
  - FastAPI model serving
  - Docker containerisation
  - Public deployment with latency percentiles and cost analysis
- **Part 2 — Transformers from first principles:**
  - RNN and BPE tokenizer (scratch implementations)
  - Self-attention and multi-head attention in NumPy
  - Small GPT trained on custom text
  - Positional encoding, softmax, masked attention

### 7. **[LLM Applications and Production Practice](https://github.com/Yugalpoudel07/LLM-Applications-and-Production-Practice)**  
*Transformer fine-tuning, RAG systems, LLM cost analysis, reproducibility.*

- **Fine-tuning:** Hugging Face transformers with LoRA against TF-IDF baseline
- **Quantization:** Cost-per-1,000-predictions analysis
- **RAG (Retrieval-Augmented Generation):** Separate metrics for retrieval vs generation
- **Reproducibility:** MLflow tracking, DVC data versioning, GitHub Actions CI, drift monitoring
